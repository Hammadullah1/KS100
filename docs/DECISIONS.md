# Engineering decisions

1. **2026-09-18 - Close source gates by default.** Official PSX terms do not establish the free research/display permissions required here. Finish local software using synthetic fixtures; do not scrape, contact providers, buy data or accept contracts.
2. **Explicit target identities.** KSE100 total return, KSE100PR price return and ex-dividend company price direction are separate.
3. **Manual normalized import first.** No undocumented PSX/SBP/NCCPL endpoint is invented. EIA's documented route is implemented but remains disabled pending a key/live-shape check.
4. **Calendar coverage is data.** Store every day, including explicit closures and notice publication times. No production weekday inference.
5. **Immutable snapshots and ledger.** Partitioned Parquet plus small JSON; a private state repository is the remote default when retention rights permit.
6. **First-final evaluation labels.** Freeze the reference close at the original cutoff and the target close at its first configured validated deadline. Later corrections remain auditable.
7. **Small model budget.** One modest LightGBM configuration and logistic regression; optional bounded out-of-time blend; separate sigmoid calibration and directional gates. No paid AI calls or GPU.
8. **Defer the neural branch.** Permitted timestamped news and a measurable cheap-feature gain are missing. Neural complexity cannot solve that dependency.
9. **Static results PWA.** React/TypeScript/Vite; hash-checked network-first results with verified local fallback, separate expiry/update deadlines and client-clock checks.
10. **Design direction: a restrained financial research journal.** Ivory paper, deep exchange green, Newsreader display and Public Sans body; clear paired probability columns and a quiet evidence panel. DFII assessment: impact 4, fit 5, feasibility 5, performance 4, consistency risk 3 - 15. These are design judgments, not user-study measurements. A fixed mobile navigation bar and single-line status keep the controls stable. Fonts are self-hosted; no marketing imagery or fabricated charts. The design-spatial companion referenced by the design-system skill was not installed; the available token/accessibility rules were applied directly.
11. **GitHub Pages target retained.** This is a local source repository and scheduled Python project, using the build plan's specified GitHub deployment architecture. No Sites project or paid hosting was created.
12. **Dependency resolution, not guessed versions.** uv resolved packages against installed Python 3.10; pnpm resolved exact frontend packages. pnpm 10.34.5's official tarball integrity was checked after npm timed out. Interpreter upgrade remains a maintenance item.
13. **No release without evidence.** Workflow files can be validated locally; only an authorized successful hosted workflow, URL smoke test and Android-browser check can establish release.
14. **2026-09-19 - Separate threshold fitting from claims.** Review found that the 63-date selection block could never meet the 100-date gate. Protocol v2 uses 20 observations/20 distinct dates for exploratory threshold fitting while retaining the independent final-test 200-observation/100-date evidence gate, the 80% lower-bound target and production validation checks. This repairs an impossible fitting condition; it does not demonstrate market accuracy. Frozen v1 reports and configurations remain preserved.
15. **Use dates for rolling pooled reports.** Review found that grouping every 63 rows could split a trading date's companies across reports. The research runner now groups 63 complete dates, preserves row/probability alignment and includes each observation once. Regression cases cover shuffled pooled rows and invalid window lengths.
