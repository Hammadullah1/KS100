# Source feasibility audit

Reviewed 2026-09-18 using official pages. No bulk market data was downloaded. Decisions apply to this project, not a general legal opinion. Machine-readable fields are in `config/sources.yaml` (generated by `scripts/init_registry.py`). Unknown permission is a closed gate.

| Source | Evidence and finding | Decision / remaining dependency |
| --- | --- | --- |
| PSX index and prices | [Indices](https://www.psx.com.pk/psx/product-and-services/indices) distinguishes total and price return. [Portal terms](https://dps.psx.com.pk/) constrain systematic retrieval and copying; [data services notice](https://www.psx.com.pk/psx/product-and-services/data-services-vending) requires rights for dissemination. A visible history page is not a verified permitted historical feed. | Bulk collection, retained research history, training, raw display and public forecasts are **not verified**. Do not enable scraping. Need a lawfully supplied dataset with explicit use evidence, history, availability and final-close definitions. KSE100 and KSE100PR must remain separate. |
| Corporate actions, membership, disclosures | Same PSX terms; download mechanism and historical vintages not verified. | Manual normalized import interfaces only; live collection disabled. Dated actions/membership required before company eligibility. |
| EIA Brent | [API documentation](https://www.eia.gov/opendata/documentation.php), [Brent history](https://www.eia.gov/dnav/pet/hist/RBRTED.htm), [reuse policy](https://www.eia.gov/about/copyrights_reuse.php). EIA-owned data may be reused with attribution. API needs an individual free key. | Adapter uses documented v2 series-ID route for PET.RBRTE.D. Authentication and response shape not verified live. First receipt is availability unless release evidence is supplied. No historical publication-vintage claim. A delayed feature is acceptable; current revised history alone cannot establish a historical backtest. |
| FRED Brent | [API terms](https://fred.stlouisfed.org/docs/api/terms_of_use.html) preserve third-party rights. | Alternate interface only, disabled until series-specific rights, free API key, and real-time/vintage treatment are reviewed. Avoid redundant Brent features. |
| SBP | [Economic data](https://www.sbp.org.pk/economic-data) reachable; linked release-calendar URL could not be retrieved in this audit. | FX definition, rights, release times and vintage history unresolved. Manual interface; no invented API endpoints. |
| NCCPL | [Market information](https://www.nccpl.com.pk/market-information) failed retrieval during audit. | FIPI/LIPI history, units, retention, release time and reuse remain unverified. Disabled. |
| PBS | [Press releases](https://www.pbs.gov.pk/press-release/) reachable. | Use actual release timestamps, never reference-month dates. Bulk/history/reuse audit and adapter sample still needed. |
| IMF / fiscal / company news | Official links in the build plan; no licensed historical text corpus supplied. | Metadata-only manual contract prepared. No sentiment model, copied article text or claimed measured contribution. |

Free production PSX data and public forecast rights remain unsolved. A private repository does not repair missing rights. Do not buy data or contact a provider automatically. Source-specific permission decisions require dated evidence, not merely toggling a flag.

Hosting: [Pages limits](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits) and [Actions billing](https://docs.github.com/en/billing/concepts/product-billing/github-actions) reviewed. A small personal research site is the proposed use. Standard public runners are currently free, but account settings, shared storage and eligibility remain unverified. No repository, deployment or paid service was created.
